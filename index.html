Hagar Arafa

I build ETL workflows that turn raw files and API data into structured, queryable databases, using SQL Server, SSIS and Python.

See selected work Download CV

I look for the structure in messy things.

I graduated in mathematics and taught it online for about two years. The work was about breaking a hard problem into clear steps, then using learner data to see where people were getting stuck.

It is the same habit I bring to databases and pipelines. I’m now in the Digital Egypt Pioneers Initiative (DEPI) Data Engineering track. I have built an SSIS ETL project and Python data-collection scripts, and I’m working on a team graduation project: a geospatial database for coastal erosion and risk mapping.

I care about the unglamorous parts that make data trustworthy: clean inputs, clear schemas and workflows that run the same way every time.
